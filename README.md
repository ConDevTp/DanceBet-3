# 💃 DanceBet

**DanceBet** – A sleek, fully responsive single-page application focused on user bio and profile presentation.  
Built with **HTML, CSS, JavaScript, Bootstrap, Flexbox, and FontAwesome**, crafted for **smooth animations, modern UI, and clean code structure**.

> ⚡ **Portfolio-Level Project** – Showcasing Senior Front-End skills with polished UX/UI, responsive design, and modular code.
